# Godot Project Template

Godot project template to get started fast with a new godot project.

Features:

- strict type checking warnings (untyped declarations, unsafe property/method access, unsafe call arguments, unsafe void return)
- mise integration (tool versioning)
- lefthook pre-commit hooks (gdscript-formatter)
- boilerplate (.gitignore, .editorconfig, .gitattributes)
- GitHub Actions CI
